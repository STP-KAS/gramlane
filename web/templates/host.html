project delusional Same principle as a Kaspa node: anyone can run this. Not Nakamoto for the jar. Vision

Why this page exists

Once a desk is public, every convert/fill is a Kaspa L1 tx to that host’s PayTo. Grams live on that host’s book. One popular URL is a centralisation threat. The honest fix that ships today is not “send the KAS to miners.” It is: run your own, on a PC, with a hardware wallet signing the fill, and a phone talking to your URL.

What is worth (security budget)

PieceWhoWorth?
L1 fee on the fillMinersYes. This is Kaspa’s security budget. Already happens.
L1 amountWhoever set GRAMLANE_PAYTOYes. Inventory for hosting. That is the join-in.
Dump the amount into extra miner feesMinersNot worth it. The cheap meter dies. Kaspa has no treasury address for “security.”

Name minting is a different split: 50% funds the name, 50% Kaspa growth vault. Fill is not that. Fill is fee → miners, amount → host.

PC

cd C:\Users\Remco\Documents\kaspa\superapp
$env:GRAMLANE_PAYTO = "kaspa:q…"   # your address, not the login you fill from
$env:PUBLIC_BASE = "https://your.example"   # the URL phones will use
$env:GRAMLANE_ADDR = "0.0.0.0:8081"         # optional; default is 127.0.0.1:8081
go test ./...
go build -o gramlane.exe ./cmd/gramlane
.\gramlane.exe

Or write the address in payto.txt (not committed). Another host is another ledger.json. Copying this exact process does not merge jars.

Phone

Install the PWA of that host. iPhone: Safari → Share → Add to Home Screen. Android: Chrome → Install app. Needs https. The phone does not hold a second gram book. Phone steps

Hardware

A hardware wallet (KasVault / Ledger path) signs the fill tx on L1. The desk is still a computer running this binary. Signing is not hosting.

What this is not

  • Nakamoto consensus for grams. That is later consume() on WorkCredit.
  • One global Circle-style issuer. Many desks ≠ one issuer. Many desks ≠ one ledger.
  • A claim that miners take the fill amount.

One line: skip centralised stablecoins for dapps. Intelligent people should look. Still a delusional idea.
